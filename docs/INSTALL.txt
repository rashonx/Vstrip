Rashon X Vocal - install on Windows
====================================

1. Unzip the download and open the "Rashon X Vocal vX.Y.Z" folder (the number is the version).
   Copy the "Rashon X Vocal.vst3" folder inside it to (replace the old one if Windows asks):
       C:\Program Files\Common Files\VST3\
2. Open your DAW and rescan plugins (FL Studio: Options > Manage plugins > Find plugins).
3. Put Rashon X Vocal on your vocal track as an insert effect.

Rashon X Vocal.exe is a standalone version you can run without a DAW (plug in a mic, use headphones).
