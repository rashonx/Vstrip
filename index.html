Plugins

Every Dodge City plugin in one place. Each button downloads the newest version for Windows.

Installing a plugin

Unzip the download and open the folder inside. Copy the .vst3 folder into C:\Program Files\Common Files\VST3\ (replace the old one if Windows asks), then rescan plugins in your DAW. Full steps are in the INSTALL.txt file in each download.
Downloads come straight from the releases page, so new versions show up here automatically.
